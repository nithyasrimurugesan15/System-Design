# 🧠 System Design Patterns

A collection of commonly used **Software Design Patterns** implemented with clean and simple examples.  
This repository helps developers understand core design principles and apply them in real-world applications.

---

## 🚀 About This Repository

This project contains implementations of important **design patterns** used in system design and object-oriented programming.

Each pattern is explained with:
- 📘 Concept
- 💻 Code Implementation
- 🎯 Use Cases

---

## 📂 Design Patterns Included

### 🏗️ Creational Patterns
- Singleton Design Pattern  
- Factory Design Pattern  

### 🔌 Structural Patterns
- Adapter Design Pattern  
- Composite Design Pattern  

### 🔄 Behavioral Patterns
- Observer Design Pattern  
- Strategy Design Pattern  

### 🧩 Other Patterns
- Abstract Design Pattern

## 📖 Example Patterns Explained

### 🔹 Singleton Pattern
Ensures only one instance of a class exists.

### 🔹 Factory Pattern
Creates objects without exposing creation logic.

### 🔹 Observer Pattern
Defines one-to-many dependency between objects.

### 🔹 Strategy Pattern
Encapsulates interchangeable behaviors.
